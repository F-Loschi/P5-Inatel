## DML:
**Lidam com a manipulação de dados presentes dentro das tabelas do BD**
### INSERT:
**Usado para inserir novos dados em uma tabela**
- Como fazer:
	- Pode ser usado passando apenas valores
	- Pode ser usado passando os atributos específicos
### UPDATE:
**Usado para atualizar dados que já estão cadastrados**
* Como fazer:
	* Atualizando uma única coluna
	* Atualizando múltiplas colunas
	* Não esquecer do WHERE, senão ele muda o negócio inteiro
### DELETE
**Usado para excluir registros**
- Como fazer:
	- Atualizando um único
	- Atualizando múltiplos registros
	- Não esquecer do WHERE, senão ele muda o negócio inteiro
